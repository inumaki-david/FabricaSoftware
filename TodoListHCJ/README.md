# Meu Dia - Lista de Tarefas (To-Do List)

Um aplicativo de Lista de Tarefas moderno, leve e intuitivo, desenvolvido com **HTML5**, **CSS3** e **JavaScript puro (Vanilla JS)**.

---

## 🚀 Funcionalidades

- **Design Moderno:** Interface limpa, cantos arredondados, fundo sutil e suporte responsivo (mobile & desktop).
- **Adicionar Tarefas:** Campo de texto com botão azul "Adicionar" ou atalho pressionando a tecla `Enter`.
- **Validação de Entrada:** Alerta caso o usuário tente adicionar uma tarefa em branco.
- **Concluir Tarefas:** Clique na tarefa ou na caixa de seleção para marcá-la como concluída (efeito tachado).
- **Excluir Tarefas:** Botão vermelho dedicado para remover a tarefa da lista.
- **Persistência com LocalStorage:** Suas tarefas permanecem salvas mesmo se a página for recarregada ou o navegador fechado.
- **Data Dinâmica e Contador:** Exibição da data atual formatada e contagem em tempo real de tarefas pendentes.

---

TodoListHCJ/

---

## 💻 Como Executar

1. Dê um duplo clique no arquivo [`index.html`](./index.html) para abri-lo diretamente no seu navegador preferido (Chrome, Edge, Firefox, etc.).
2. Ou utilize a extensão **Live Server** no VS Code para abrir com recarregamento automático.
